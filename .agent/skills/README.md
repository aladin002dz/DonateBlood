# Antigravity Skills

This directory contains skills that extend the capabilities of the Antigravity agent.
Each subdirectory represents a skill and must contain a `SKILL.md` file with instructions.

## How to add a new skill

1. Create a new folder in this directory (e.g., `my_new_skill`).
2. Create a `SKILL.md` file inside that folder.
3. Add YAML frontmatter to `SKILL.md` with `name` and `description`.
4. Write detailed instructions in `SKILL.md`.
